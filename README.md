# FPGA Experiments

## Purpose

This repository documents experiments and learning in FPGA development, including hardware description language (HDL) design, toolchain usage, and physical validation on real hardware.

## Learning Scope

This repository covers the following areas of FPGA learning and experimentation:

- **Toolchain**: FPGA vendor toolchains (e.g., Vivado, Quartus, SymbiFlow, openFPGA toolchains), version management, and workflow.
- **HDL**: Verilog, SystemVerilog, and/or VHDL design — from simple modules to complex systems-on-chip.
- **Constraints**: Pin assignments, timing constraints, power constraints, and I/O standards.
- **Simulation**: Testbench development, simulation setups, and result analysis using simulation tools.
- **Physical Validation**: Bitstream generation, programming FPGAs, on-board testing, and signal-level verification.

## Current Status

**No bitstreams or hardware demos have been completed yet.** This repository is being set up with structure, templates, and guidelines for future work.
